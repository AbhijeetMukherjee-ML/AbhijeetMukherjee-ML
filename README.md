## Featured Projects

### 1. Football Manager

**A Football Management Simulation Game**

[View Repository](https://github.com/AbhijeetMukherjee-ML/football-manager)

An in-development football management game where players take the role of a football club manager, managing their squad, tactics, and matches.

**Key Features:**
- Interactive football management dashboard and squad management.
- Tactical formations and team strategy.
- Custom football match simulation engine.
- 3D match viewer with player movement and match events.
- Modular simulation engine with seeded randomness and event-driven match logic.
- Database support for persistent game data.

**Technologies:**
`TypeScript` `Next.js` `React` `Three.js` `React Three Fiber` `PostgreSQL` `SQLite` `Electron`

### 2. BudgetWise CLI

**Command-Line Personal Finance Manager**

[View Repository](https://github.com/AbhijeetMukherjee-ML/budgetwise-cli)

A terminal-based personal finance application built in Java to manage income, expenses, monthly budgets, and spending insights.

**Key Features:**
- Add, list, search, and delete financial transactions.
- Set monthly budgets for different spending categories.
- Track remaining budgets and category-wise expenses.
- Generate monthly financial summaries.
- Persistent local storage using text files.
- Input validation and modular application architecture.

**Technologies:**
`Java` `OOP` `File Handling` `CLI`
